Advanced Maintenance

Targeted operations for specific recovery and maintenance scenarios. Use these when standard sync options are insufficient.

Skips catalog refresh — directly parses catalog entries not yet stored locally.
Retries only pages that previously failed or parsed partially. Does not refresh the catalog.
Rebuilds the game save location index from stored PCGW data without re-fetching anything from the internet.
Updates the list of known game IDs from PCGamingWiki without parsing any page content.
Forces a complete reparse of all PCGW pages from scratch, bypassing resume. Rarely needed — prefer Incremental Sync for routine updates.
Removes compressed wikitext blobs to reclaim disk space. Safe to run — data can be re-fetched on next sync.
