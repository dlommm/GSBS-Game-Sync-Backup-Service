Getting Started

Fresh setup checklist for your first sync.

  1. Review server options in Settings (cron and first-start sync behavior).
  2. Open PCGW and run Phase 1+2: Refresh IDs and Parse/Store Backlog to populate catalog and manifest entries.
  3. Create client tokens and users in Users & Clients.
  4. Install and log in from a client, then verify saves appear on Dashboard.
