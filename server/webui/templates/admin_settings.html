Sync source

Choose how the server updates PCGW mirror data. The S3 bundle is a prebuilt snapshot fetched from object storage (Cloudflare R2/S3) and avoids direct PCGW API calls. Switching to Manual imports the S3 bundle once to seed, then runs only on-demand PCGW API syncs.

Notifications

Server alerts via plain HTTP — a generic webhook (JSON), a Discord webhook, and/or an ntfy topic URL. Leave a field empty to disable that channel. Users can additionally set personal channels in their own Settings.

Version Retention Overrides

Per-game override of how many save versions are kept (global default: GSBS_SAVE_VERSION_RETENTION). JSON object of game ID to count (1–50), e.g. {"12345": 20}. Applies within a minute of saving.

Sync Safety

Rejects a push that carries no safety precondition when the save was last written by a different device — the older client records it as a conflict instead of overwriting. Clients 4.0+ always send preconditions, so this only affects fleets still running 3.x. May surface conflicts on legitimate alternating play under last-write-wins; leave off unless you need it.

Cover Art Cache

Game covers are pulled from Steam's public CDN on demand and cached on disk, then served locally to My Games. Games without Steam art fall back to a generated icon. Clearing the cache forces covers to re-download on next view.
