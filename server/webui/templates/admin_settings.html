PCGW Sync

Sync source

Choose how the server updates PCGW mirror data. The S3 bundle is a prebuilt snapshot fetched from object storage (Cloudflare R2/S3) and avoids direct PCGW API calls. Switching to Manual imports the S3 bundle once to seed, then runs only on-demand PCGW API syncs.

{{if .PCGWSyncSourceEnvOverride}}

Sync source is controlled by the GSBS_PCGW_SYNC_SOURCE environment variable.

{{end}}
