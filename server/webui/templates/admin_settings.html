Version retention

Per-game override of how many save versions are kept (global default: GSBS_SAVE_VERSION_RETENTION). JSON object of game ID to count (1–50), e.g. {"12345": 20}. Applies within a minute of saving.

Sync safety

Rejects a push that carries no safety precondition when the save was last written by a different device — the older client records it as a conflict instead of overwriting. Clients 4.0+ always send preconditions, so this only affects fleets still running 3.x. May surface conflicts on legitimate alternating play under last-write-wins; leave off unless you need it.

Catalog filters

Substring excludes applied during API sync. Path excludes use defaults when empty.

{{if .TLSActive}}

This page was served over HTTPS{{if .NativeTLS}} by GSBS's built-in TLS listener{{else}} (via your reverse proxy){{end}}. Passwords, tokens, and saves travel encrypted.

{{else}}

GSBS is currently reached over plain HTTP — passwords and sync tokens travel unencrypted on your network. There are two ways to enable HTTPS; both are server-side (no toggle here, because GSBS can't issue certificates for itself):

{{end}}
  • Reverse proxy (recommended): the bundled Docker Compose ships a Caddy proxy that terminates TLS — including automatic Let's Encrypt certificates when you have a public domain. See docs/COMPOSE.md and docs/Caddyfile in the repository.
  • Built-in TLS (LAN / self-signed): point GSBS at a PEM certificate and key, then restart:
    GSBS_TLS_CERT=/path/fullchain.pem GSBS_TLS_KEY=/path/privkey.pem
    For a LAN address, generate a self-signed cert (openssl req -x509 -newkey ec -pkeyopt ec_paramgen_curve:prime256v1 -keyout key.pem -out cert.pem -days 825 -nodes -subj "/CN=gsbs.lan" -addext "subjectAltName=IP:YOUR.SERVER.IP") — clients and browsers must then trust it.

After switching, update every client's server URL to https://… (tray → Account & Setup → Login).
