Conflicts

When two devices change the same save, the server keeps its copy and every version stays in history. Nothing is lost.

{{template "partials/conflicts_list.html" .}}

How it resolves

Keep the server's copy
Dismiss the conflict here. The device picks the server's copy up according to its conflict policy.
Keep the device's copy
On that device, open the tray, choose Resolve conflicts, then Keep all local files. Its next push replaces this conflict.
Rescue any version
Nothing is deleted. Open the file's version history to download or load an older copy.
Stop it happening again
Set a per-game conflict policy (last write wins, keep local or keep server) in each device's settings.
