# Getting help with GSBS

- **Setup & usage questions** — start with the [wiki](../../wiki) ([Installation](../../wiki/Installation), [Server Configuration](../../wiki/Server-Configuration), [Troubleshooting](../../wiki/Troubleshooting), [FAQ](../../wiki/FAQ)), then ask in [Discussions](../../discussions).
- **Bugs** — open a [bug report](../../issues/new?template=bug_report.yml). Attach client diagnostics (tray → Advanced → Copy diagnostics; secrets are stripped automatically).
- **Feature ideas** — open a [feature request](../../issues/new?template=feature_request.yml).
- **Security vulnerabilities** — never open a public issue; follow [SECURITY.md](SECURITY.md).

GSBS is free, open-source software maintained in spare time — clear reports with versions, platforms, and logs get fixed fastest.
