Help

What the statuses mean and how to fix common problems.

Status reference

ConnectionWhether this PC has a valid login to your GSBS server. "Re-login required" means the token was revoked — open Setup and sign in again.
Last syncWhen the most recent push/pull cycle finished, and whether it succeeded.
WatcherThe file watcher that notices save changes instantly. "Recovering" fixes itself; syncing continues on the interval either way.
Pending uploadsSaves queued while the server was unreachable. They retry automatically for 7 days.
ConflictsThe same save changed on two PCs. Your conflict policy decided which copy won; details in Insights.

Quick troubleshooting

  1. Not connected? Open Setup and log in with your server address and account.
  2. A game isn't syncing? Check it appears under Status → Matched games; if not, add its save folder.
  3. Sync errors? Check Logs with the level filter on error.
  4. Unexpected save contents? Restore any older version from the server dashboard → My Games → the file's history.
  5. Still stuck? Open the log file and attach it to a GitHub issue.
